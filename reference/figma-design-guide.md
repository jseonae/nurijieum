## 2. 전체 틀

- 기준 화면: 1920 × 1080 이상, 세로는 내용에 따라 늘어남
- **왼쪽 메뉴(side-nav)**: 폭 240, 흰 배경, 오른쪽 1px 구분선
  - 맨 위 「대시보드」 단독 항목(아이콘 + 굵은 글씨)
  - 구역 제목 「사이트 관리」「운영관리」: 회색 작은 글씨 + 오른쪽 접기 화살표(펼침 ∨ / 접힘 ›)
  - 하위 항목: 들여쓰기한 검정 글씨. 현재 항목은 연한 파랑 배경 + 파랑 글씨 + 둥근 모서리
  - 맨 아래 「도움이 필요하신가요? 사용자 매뉴얼 바로가기」 초록 안내 카드(초록 말풍선 아이콘)
- **머리 막대(header)**: 높이 66, 진한 파랑 배경(blue-900 `#0033a9` 계열)
  - 왼쪽: 메뉴 접기(≡), 「누리지음 CMS」 로고, 사이트 선택(둥근 알약 테두리 + ∨), 「메뉴 및 콘텐츠 검색」 둥근 검색창
  - 오른쪽: 사이트 바로가기(지구 아이콘) | 글자·화면 설정(눈 아이콘) | 알림(종 + 빨간 점) | 사용자(원형 아이콘 + 이름·접속 IP + ∨)
- **본문**: 연한 회청색 배경(`#f6f8fc` 계열). 좌우 여백 38, 위 여백 32
- **바닥글**: 높이 56. 「© 2026 누리지음CMS Core. All rights reserved.」 | 「Build Version: 2.4.11-STABLE」
- 오른쪽 아래 「맨 위로」 원형 버튼(38 × 38)

## 3. 페이지 머리(Page Header) 3종

1. **목록형**: 큰 제목(약 28, 굵게) + 오른쪽에 붙은 작은 회색 설명 한 줄. 오른쪽 끝에 주요 버튼(파랑 채움 「+ 새 ○○ 등록」, 필요하면 왼쪽에 파랑 테두리 보조 버튼 「+ 메뉴 일괄등록」)
2. **하위 목록형**: 위에 경로(「게시판 > 공지사항 > 게시글 관리」), 제목의 앞부분은 파랑 강조(「**공지사항** 게시글 관리」, 「**대표포털** 도메인 관리」, 「**CMS Operator** 권한 관리」). 오른쪽에 「← ○○ 목록으로」 테두리 버튼
3. **등록·수정형**: 흰 막대(높이 72)로 본문 위에 붙음. 왼쪽 「←」 네모 버튼 + 제목(「메뉴 등록」). 오른쪽 「자동 저장됨 · 2분 전」 회색 글씨 + 버튼 묶음
   - 등록: 취소(회색 채움) · 등록하기/게시하기(파랑 채움)
   - 수정: 삭제하기(빨강 테두리) · 수정하기(파랑 채움)
   - 글쓰기 화면은 미리보기 · 임시저장(흰 테두리) 추가

## 4. 탭(cms_tab)

- 본문 폭 전체(1604)를 같은 너비로 나눈 막대형 탭, 높이 46
- 선택: 진한 남색 채움(`#083891` 계열) + 흰 굵은 글씨
- 비선택: 연한 회청색 채움 + 회색 글씨, 둥근 모서리
- 사용처: 메뉴/라우트(2개), 감사 로그(2개), 권한(4개: 권한 그룹 명단 · 역할 관리 · 서브관리자 계정 · 접속 IP 관리)

## 5. 목록 화면 구성

흰 카드(둥근 모서리, 옅은 그림자) 한 장 안에 **필터 막대 → 표 → 쪽 번호** 순서로 둡니다.

### 5-1. 필터 막대(list_filter, 높이 74)
- 왼쪽: 「총 **24**개」(숫자 파랑) · 「목록 표시 개수 15개 ∨」 | 「선택 1개」 · 「선택삭제」(빨강 연한 채움 + 휴지통) | 「+ XML생성」 · 「상태변경」 · 「엑셀다운로드」(흰 테두리 작은 버튼)
- 오른쪽: 기간(달력 아이콘 날짜 칸 2개) · 선택상자(상태, 분류, 메뉴 유형 등) · 검색창(「검색어를 입력하세요」 + 돋보기)
- 미디어는 맨 오른쪽에 목록형/카드형 보기 전환 아이콘
- 통합회원은 선택상자 대신 체크 칩(전체 · 활성 · 중지 · 탈퇴)

### 5-2. 표
- 머리 줄: 높이 44, 연한 회청색 채움, 회색 작은 글씨
- 본문 줄: 높이 50, 줄 사이 옅은 구분선. 마우스를 올리면 연한 파랑 배경
- 선택한 줄: 체크 + 제목이 파랑 글씨(「인사말」, 「공지사항」)
- 맨 왼쪽 체크박스, 다음 번호(회색, 내림차순)
- **하위 목록형 표**(게시글, 도메인, 코드, 권한)는 줄마다 둥근 테두리 칸으로 띄워 놓고, 선택한 줄은 파랑 테두리
- 맨 오른쪽 「작업」 열: 세로 점 3개(⋮) 하나만 둠
- 권한 화면 일부는 ⋮ 대신 작은 아이콘 버튼(수정 · 권한 · 삭제, 회색 테두리 네모)이나 토글·열쇠 아이콘을 둠

### 5-3. 더보기 메뉴(more menu)
- ⋮를 누르면 오른쪽 아래로 흰 카드(그림자 shadow2, 둥근 모서리)
- 항목: 아이콘 + 글씨, 높이 35. 마우스를 올리면 연한 회색 채움
- 화면별 항목
  - 메뉴·라우트·팝업존·코드: 수정하기 · 삭제하기
  - 콘텐츠·게시글: 미리보기 · 수정하기 · 삭제하기
  - 게시판: 미리보기 · 수정하기 · **게시글 관리** · 삭제하기
  - 미디어: 미리보기 · 수정하기 · 다운로드 · 삭제하기
  - 사이트: 사이트 수정 · 도메인 관리 · 삭제하기
  - 공통코드: 그룹 수정 · 코드 관리 · 삭제하기
  - 통합회원: 수정하기 · 비밀번호 재설정 · 삭제하기
  - 직원: 수정하기 · 부서 복사 · 부서 이동 · 삭제하기

### 5-4. 쪽 번호(pagination)
- 오른쪽 정렬: 「‹ 이전」 1 2 3 … 10 「다음 ›」
- 현재 쪽: 진한 남회색 네모 채움 + 흰 숫자

### 5-5. 메뉴 트리 표현
- 메뉴명 앞 단계 번호 동그라미(1 → 4로 갈수록 연해짐: 남색 → 파랑 → 연파랑 → 회색)
- 단계마다 약 18씩 들여쓰기. 경로 보조 줄은 없음

## 6. 상태 배지

작은 둥근 네모, 연한 채움 + 같은 색 계열 글씨.

| 의미 | 예 | 색 |
|---|---|---|
| 사용·출력·공개 | 사용, 출력중, 공개, 사용중 | 연한 파랑 |
| 정상·진행 | 게시중, 활성, 운영중, 허용, up | 연한 초록 |
| 대기 | 승인대기, 예약게시, down | 연한 주황 |
| 보류·비활성 | 임시저장, 미사용, 비공개, 비활성, 중지, 거부, 탈퇴 | 연한 회색 |
| 반려·위험 | 반려, 이용정지 | 연한 빨강 |

## 7. 등록·수정 화면(전체 화면형)

- 메뉴·콘텐츠·게시글·팝업존 등록/수정에 씀
- 2단: 왼쪽 본문 카드(1160) + 오른쪽 설정 카드 열(420), 사이 24
- 왼쪽 카드: 항목 이름(굵게, 필수는 빨강 *) 아래 입력 칸. 칸 아래 작은 회색 안내(「* 선택한 메뉴의 하위 메뉴로 등록됩니다.」)
- 오른쪽 열: 작은 카드 여러 장. 각 카드는 제목 + 토글/입력 하나
  - 메뉴: 노출여부(토글) · 정렬순서
  - 콘텐츠·게시글: 카테고리 분류 · 게시 여부 설정(게시중/임시저장/예약 게시 라디오) · 태그 설정(칩 + 입력) · 대표 썸네일(점선 끌어놓기) · 첨부파일
  - 팝업존: 팝업 미리보기 · 위치 · 노출여부 · 정렬순서
- 글쓰기 본문: 큰 제목 칸(「제목을 입력하세요.」) + 편집 도구 막대(B I U H1 H2 목록 링크 이미지 코드) + 본문
- 링크 URL: 「현재창 ∨」 선택상자 + 주소 칸을 나란히
- 담당자: 오른쪽 위 「담당자 찾기」 작은 버튼 → 검색 모달. 선택 뒤에는 회색 정보 칸(「홍길동 홍보협력담당관 / 041-350-3140 · 메일 · 아이디」) + 「담당자 변경」

## 8. 측면 패널(panel_form)

- 오른쪽에서 나오는 패널. 폭 476(회원·직원은 516), 연한 회청색 배경, 왼쪽 위·아래 큰 둥근 모서리
- 머리: 제목(굵게) + 오른쪽 ✕
- 몸통: 항목마다 흰 카드 한 장(제목 + 입력 하나). 회원·직원은 「필수 입력 사항」「선택 입력 사항」「기본 정보」「직원 정보」처럼 묶은 카드
- 바닥: 오른쪽 정렬 「취소」(흰 테두리) · 「등록」/「수정」/「확인」(파랑 채움)
- 안내 글은 바닥 버튼 위 「※ 비밀번호는 1회용 임시 비밀번호로 발급되며 재조회할 수 없습니다.」
- 회원·직원은 위에 원형 사진(카메라 배지) + 「프로필 사진은 3MB까지 선택할 수 있습니다.」

## 9. 모달

- 흰 카드, 큰 둥근 모서리, 진한 그림자, 뒤 배경은 어둡게(dim `#000000bf`)
- 제목(크게, 굵게) + 설명 한 줄 + 오른쪽 ✕
- 담당자 검색: 부서 선택 · 검색 항목 선택 · 검색창 · 「검색」 → 「총 1,587명」 → 라디오 표(선택 줄 연한 파랑) → 쪽 번호 → 「취소」「선택」
- 글자·화면 표시 설정: 글자 크기 5단계 라디오 + 화면 모드 3종(기본/선명하게/시스템, 미리보기 그림) → 「초기화」「설정」

## 10. 요약 카드(cms_summary)

- 목록 위 흰 카드 3~4장 가로 배치(사이트 · 게시글 · 운영 진단 · 확장 서비스)
- 왼쪽: 이름(회색) + 큰 숫자(굵게). 오른쪽: 입체감 있는 색 아이콘(파랑 책·초록 체크·노랑 시계·보라 디스켓·회색 금지)

## 11. 대시보드

- 「Today 2026. 09. 08. 금」 칩 + 「안녕하세요, 전체관리자님」 큰 인사
- 오른쪽 「현재 **대표행정** 사이트를 관리중입니다.」 + 「사이트 변경 ∨」
- 1줄: 사이트 운영 현황(반원 게이지 + 운영중/중지/점검대상) · 콘텐츠 처리 대기(파랑 채움 카드, 「2건」) · 운영 진단(파랑 채움 카드, 「1건」)
- 2줄: 콘텐츠 운영 현황(연한 파랑 바탕 안에 콘텐츠/게시판/팝업존/미디어 카드 4장, 건수 + 상태별 점)
- 3줄: 최근 콘텐츠(분류 테두리 칩 + 제목 + 「5분 전」 + 상태 배지) · 최근 시스템 활동 로그(시간 + 파랑 점 타임라인)

## 12. 빈 상태
