# 누리지음 퍼블리싱 키트

- 기준: `71d77aa522`, 2026-11-04
- 대상: 「CMS 관리 통합 시안」의 새 기능 화면. 서버 없이 `index.html`을 더블클릭해서 엽니다.
- 데이터: 전부 목데이터입니다. 저장·조회는 동작하지 않습니다.

## 폴더

| 폴더 | 내용 | 수정 |
|---|---|---|
| `pages/` | 화면·탭·모달 상태별 HTML. 머리 주석에 반영 위치가 있습니다 | 가능 |
| `static/` | 저장소 `static/`과 같은 경로의 실제 CSS·JS | 가능(`vendor/krds/` 제외) |
| `static/admin-ui/v2/new-features.css` | 새 기능 화면 전용 CSS | 가능 |
| `static/admin-ui/v2/pub.js` | 로컬 미리보기 전용 스크립트. 실제 콘솔에 들어가지 않습니다 | 불필요 |
| `reference/` | 통합 시안 원본(참고용). 아래 「시안과 다른 곳」을 먼저 보세요 | 불필요 |

## 수정 규칙

1. `nv-*` 클래스 이름과 `data-*` 속성을 유지합니다. 스크립트가 여기에 걸려 있습니다.
2. `vendor/krds/`는 고치지 않습니다.
3. `cms-admin-v2.css`·`cms-design-system.css`에는 색상값을 직접 쓰지 않고 `--cms-*` 토큰만 씁니다. 새 값은 `shared/nuri-tokens.css`에 추가합니다.
4. 고친 `static/` 폴더와 `pages/`를 그대로 돌려주세요. 개발팀이 경로대로 비교해 반영합니다.
5. HTML은 개발팀이 서버 템플릿으로 옮깁니다. 표와 입력 칸의 구조는 유지하고, 글자 값은 목데이터로 봐 주세요.

## 시안과 다른 곳

2026-11-04 콘솔 메뉴 목록이 시안보다 우선입니다.

- 「CMS 메뉴 관리」 → 「메뉴관리」, 「접속 기록」 → 「접속기록」, 「사이트」 → 「사이트 관리」
- 「관리자메뉴관리」는 만들지 않습니다.
- 이미지, 부서 및 조직, 운영 진단, 연결 서비스 링크는 사이드바에서 숨깁니다.
- 그룹묶음(부서)은 보류입니다.
- 서브관리자 등록은 직접 입력 + 임시 비밀번호입니다. `pages/auth-account-add.html`은 시안에 없고 현재 콘솔의 관리자 계정 등록 패널에서 가져왔습니다. 연락처·부서명·이메일 칸은 목록 표와 메뉴 담당자 칸에 맞춰 더했습니다.

## 알아 둘 점

- 툴팁 문구에는 시안의 출처 표기(당진·국특원)가 남아 있습니다. 문구는 개발 때 정리합니다.
- 소스 수정 탭의 편집 영역은 시안의 간이 편집기입니다. 실제 콘솔은 SunEditor를 씁니다.
- KRDS `component.css`는 라벨 안의 맨몸 체크박스를 `!important`로 숨깁니다. `new-features.css` 끝에 표 칸·칩 체크박스를 되살리는 규칙이 있으니 지우지 마세요.
- `reference/`의 시안에는 설명 페이지와 외부 링크가 그대로 있습니다. 전달 범위를 정할 때 참고하세요.
